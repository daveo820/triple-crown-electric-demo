# Triple Crown Electric: concept site by LuminArch

A pitch demo for Triple Crown Electric LLC (Garner, NC). **Not the official site.** Noindexed, blocked in robots.txt, and labeled with a concept banner on every page.

- Live preview: https://daveo820.github.io/triple-crown-electric-demo/
- Pages: home, services, permit record, reviews, free estimate, 404
- Stack: static HTML, CSS and one small JS file, generated by `build.py` (run `python3 build.py`). No framework, no build tools.
- Facts and sources: `FACTS_LOG.md`. Design decisions: `DESIGN_DNA.md`. Competitor research: `market-research.md` and `research/`.
- Screenshots: `screenshots/index-desktop-fold.png` and `screenshots/index-mobile-fold.png`.

Before launch: swap the GitHub Pages URLs in `build.py` for the real domain, remove the concept banner and noindex, replace robots.txt, connect the form, and clear every TODO-VERIFY in the facts log.
